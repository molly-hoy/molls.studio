# Moll’s Studio — project files

The source files for the Moll’s Studio website: a craft site with patterns, a chart maker, a gauge calculator, a pattern maker, a shop, a community page and a scrapbook board of things Moll has made.

## Folder layout

- **`index.html`** — page structure and content: header and menu, every page section, SVG artwork, forms, chart-maker controls, pattern maker and footer.
- **`style.css`** — all styling: colours, typography, backgrounds, responsive layouts, cards, buttons, splash screen and page themes.
- **`script.js`** — all behaviour: chart drawing and tools, patterns, shop, posts, written instructions, PDF exports, gauge calculator, creations board, accounts, music player and navigation.
- **`published-charts.js`** — source data for the site’s Colour charts and charts published through the chart maker. Keep this file and its script tag in `index.html`; replace it with the export from **All publications** to make browser-published charts part of the deployed website.
- **`html-to-image.js`** — a small library (loaded by `index.html`) that takes a picture of a pattern page so it can be saved as a PDF that looks like the website. Keep it in the main folder.
- **`images/`** — all pictures (see below).
- **`music/`** — the songs (`teardrop 2026.wav`, `HARDGROOVE 1 MASTER.wav`).
- **`.vscode/launch.json`** — optional VS Code setting for running the site.

## Run the website

1. Extract the ZIP into a folder and open it in Visual Studio Code.
2. Use the **Live Server** extension (or another local web server) and open `index.html`. A server is needed for music to play and for the creations board to find new pictures; opening the file directly may block some of this.
3. Keep all the files and folders together so the pages can find each other.
4. The site uses Google Fonts, so fonts need an internet connection.

No build step or installs are needed.

Home, Shop, Patterns ▾, Charts ▾, Tools ▾, Community, Inspire me, My stuff ▾, and **Log in** at the top right. The **My stuff** dropdown includes a **My stuff** home link plus **My patterns**, **My charts**, and **Project journal**; the home page also has buttons for the three separate pages.

- **Patterns ▾:** All patterns, and Browse by craft (Knit and Crochet, each with categories). The All patterns page has a **Create your own here** section at the top with the Pattern maker and the Pattern generator side by side.
- **Charts ▾:** All charts, **Colour** (with **Animal print** as its only submenu), Lace, Cable and Texture. The page of ready-made charts has a **Create your own here** section at the top with a button for each chart type.
- **Tools ▾:** All tools, then Patterns, Charts, Calculators and Trackers. Each opens its own page listing just the tools in that group, with buttons at the top to hop between the groups and All tools: **Patterns** (Pattern maker, Pattern generator), **Charts** (Colourwork, Cable, Lace and Textured stitch chart makers, Ready-made charts), **Calculators** (Gauge calculator, Materials cost calculator, Increase or decrease evenly), **Trackers** (Row and stitch counter). ## Adding things

### Pictures to Moll’s creations (automatic)
Save pictures in `images/creations/` named **1, 2, 3 …** (`.jpg`, `.jpeg`, `.png` or `.webp`). They appear on the board with no code changes, mixed into a random order on every visit. A gap of up to 3 missing numbers is allowed; a bigger gap stops the search.
The board shows 12 pictures, then a **Load more pictures** button. Change `CR_PAGE` in `script.js` to show more or fewer at a time.
For a picture with a Crochet/Knit tag or a “See the pattern” button, add a line to the `CREATIONS` list in `script.js`: `{src:'images/file.jpg', c:'crochet', p:'pattern-id'}`. Stickers come from `images/stars/`.

### Patterns
Patterns are in the `PAT` list in `script.js`. Each has an id, name, craft (`c`), category (`g`), level (`l`), main photo (`img`), extra photos at the end (`more`), description, materials and `steps`. The button at the bottom of each pattern page saves a PDF that looks like the page; **Save to My Patterns** beside it saves a copy on this device. To add another photo to a pattern, add a `{src:'images/…', alt:'…'}` to its `more` list. A missing file is simply left out.
Current patterns: Checkerboard Hat, Granny Square Scarf, Stripy Scarf, Cow Print Shoulder Bag, Cat Hat.

### Charts
Built-in cable charts are in the `P` list in `script.js`; all six site colourwork charts are publication records in `published-charts.js`. Use `t` for chart type and optional `cat` for a category. The Charts page has search and category filters; colour charts are grouped under **Colour**, with animal-print charts under **Animal print**. Add new categories through the chart publisher or in `CHART_CATEGORIES`. Results render 48 at a time.

Use **Publish** in the chart maker to add a chart to this browser; the checked option also downloads an updated `published-charts.js` source file. Open **Manage publications** on the Charts page to edit or delete publications, then use **Download website chart data** to export the current set. Browser publishing cannot write directly to project files: replace the project’s `published-charts.js` with the downloaded file and deploy the updated project. The built-in and code-published charts then remain in the website even if the publisher and manager are later removed. Browser-only publications are not shared with other visitors until the exported file is added to the deployed site. Current charts: Cow print bag panel, Cherries, Heart, Leopard print, Cheetah print (both tile seamlessly when resized), Smiley and 4 cable chart.
- Cable symbols **C2F, C2B** take 2 squares and **C4F, C4B** take 4 squares in the chart maker. Placing, erasing or overwriting works on the whole cable.

### Shop
Listings are in `SHOP_LISTINGS` near the top of `script.js`. Each has a title, category, price, `added` date, `status` (`available` or `sold`, with `soldAt` for sold items), a picture path and an optional `pattern` id for a “See the pattern” button. Currently there are six sold listings and none available. This static site has no checkout; Buy buttons only show a “coming soon” message.

### Music
Put audio files in `music/` and add `{title:'Song title', src:'music/file-name.wav'}` to `MUSIC_TRACKS` in `script.js`. The player has previous/next buttons and plays through both tracks.

## Other features

- **Enter screen:** logo and an ENTER button; the doors open, the home page appears and the music starts (once per visit).
- **Beanie generator (Tools):** a 3-step wizard (crown, size and colour; yarn and gauge; pattern) for your Classic Folded Cuff Beanie. There is one beanie with a 2x1 rib cuff and stockinette body, and you choose the crown: **Quick crown** (two stitches lost in each section on every decrease round, with a plain round between) or **Gradual crown** (one stitch lost in each section, longer). Each crown has its own white picture with a transparent background: `images/classic-beanie.png` (quick) and `images/classic-beanie-2.png` (gradual), also stored as text in `images/beanie-photo.js` and `images/beanie-photo-2.js` so the colour picker and PDF work when the site is opened from the folder. To change a picture, that text file has to be re-made from the new picture. The wording and maths are in `beanieCalc()` and `beanieDoc()` in `script.js`; sizes are in `BEANIE_SIZES` and yarns in `BEANIE_YARNS`. The choices are stored in the page address (for example `#beanie?crown=2&size=m`). Yarn amounts are estimates.
- **Materials cost calculator (Tools):** enter what one garment needs, what one pack costs and what you already own. It works out the packs to buy, the total, the cost per garment and a shopping list. **Add a pattern from the website** fills in the materials from any pattern (or from the beanie generator), and the only thing you type is the price of a skein. **Add to my shopping list** saves the items in a tick-off shopping list at the bottom of the page, which can be copied or downloaded as a PDF to print. Every pattern page has a **Shopping list and cost** section with its yarn usage, a box for the price of one skein that shows what the pattern costs to make, and a link to the calculator (this section is left out of the pattern PDF). The beanie generator has a **Work out the cost** button that fills in the yarn amount. Everything is remembered in the browser only.
- **Yarn usage for each pattern:** each pattern in the `PAT` list in `script.js` has a yarn weight `w` (0 to 7) and a `use` list in grams, for example `w:5,use:[{n:'Colour A: pink',g:140,est:1}]`. The site turns grams into yards with the `YARN_W` table (your “Yards in 100 g of yarn” chart, using the middle of each range), so thicker yarn gives fewer yards per 100 g. `est:1` marks an estimate (remove it once you have a measured figure). The pattern page shows the **Yarn amount** row (yards, metres and grams, plus the yarn weight), and has a **Yarn weight you will use** box: a thicker yarn means fewer yards in each 100 g skein, so more skeins and a higher cost. The same table is shown on the cost calculator page, with the US name and the UK name (for example Bulky #5 = Chunky, Light #3 = DK, Medium #4 = Worsted or Aran); the UK names are in `YARN_W` as `uk`, and the dropdown and Yarn amount row show them too. Each pattern page has a **Change the yarn** box (below the materials) where the visitor picks a yarn weight (US and UK names). With the same stitch counts, the size, yarn amount and cost change: stitches per 10 cm for each weight are in `YARN_W` as `g`, suggested needles/hooks as `nd`/`hk`, and the pattern's finished measurements are its `dims` list (for example `dims:[['Width',18]]`, in cm, my estimates). The box also says how much to multiply stitch and row counts to keep the original size. The choice is remembered in the browser and the box is left out of the pattern PDF. Yarn amounts come from your average yardage table (`YARN_PROJ` in `script.js`: adult hat, afghan, sweater, scarf, mittens and socks for each yarn weight). A pattern's `ty` is its project type, `t` is where it sits in that range (0 = smaller, 1 = larger; raise it for bigger sizes) and `sh` is each colour's share of the total. Crochet patterns are multiplied by `CROCHET_X` (1.3, as crochet uses more yarn), and the grams come from the yards per 100 g table. Patterns without a project type (the Cow Print Bag) still use the older gram estimates. When a different yarn weight is chosen, the instructions are rewritten with scaled stitch and row counts so the finished size stays the same (thicker yarn: fewer stitches, rows and yards; thinner yarn: more). Scale factor = stitches per 10 cm of the pattern's yarn weight ÷ stitches per 10 cm of the chosen weight (`YARN_W`, field `g`). The rewriting is in `PAT_SCALE` in `script.js`, one function per pattern (Stripy Scarf, Granny Square Scarf, Cat Hat, Checkerboard Hat); counts are rounded to the stitch repeat (for example the checkerboard hat to a multiple of 12). Chart-based patterns such as the Cow Print Bag keep their stitch counts, so their size changes instead. To make a new pattern scale, add its id and a function to `PAT_SCALE`. The current gram figures are my rough estimates and should be replaced with your real usage.
- **Increase or decrease evenly (Tools):** enter the stitches you have and how many to add or take away, choose knitting or crochet, flat or in the round (and M1 or kfb for knitted increases). It spaces them evenly and writes the instruction in two styles, **Easy to remember** (bigger groups together, for example “K6, (M1, k7) twice, (M1, k6) 10 times”) and **Most even**, shows the new stitch count, has a Copy button, and draws your row as squares with each increase or decrease marked. In flat rows the shaping is kept away from the edges. **You can decrease all the way down to 1 stitch** (like the top of a hat): a row can only take away half its stitches with k2tog, so bigger decreases become a row-by-row plan (for example 80 → 40 → 20 → 10 → 5 → 3 → 2 → 1), with an “all in one row” version using k3tog, k4tog and so on, and a note on how to finish a hat. **Over how many rows/rounds** (optional) spreads the shaping over the number of rows you choose, as evenly as possible (left empty it uses as few as possible, and it tells you the minimum if you ask for too few). **Plain rows/rounds in between** (0 to 3) adds plain rows between the shaping rows and numbers every row. The total line always shows how many rows of shaping it takes, and how many rows in total. Your last entries are remembered in the browser. The code is the “increase or decrease evenly” section of `script.js`; the page is `<section id="evenly">` in `index.html`.
- **Row and stitch counter (Tools):** one counter card per project, each with a row count and a stitch count, big + buttons (and −, +10 for stitches), optional total rows and stitches per row (it shows “of 60” and says when all rows are done), a tick box so a new row restarts the stitches at 0, a notes box, reset and delete. Everything is saved in the browser only. The code is the “row and stitch counter” section at the end of `script.js`.
- **Gauge calculator:** enter a swatch size and stitch and row counts to get stitches and rows for any measurement. Entries are remembered in the browser.
- **Pattern maker:** from Tools. Add project details, a saved colourwork chart, instruction sections and up to six photos, then save to My Patterns or export PNG or PDF. Patterns and photos use browser storage.
- **Log in / sign up:** accounts are stored only in the browser, so this is not real security and nothing is sent to a server.
- **Page headings:** every page heading gently waves (each letter bobs one after the other), with a pink and mint colour split (like chromatic aberration) that drifts, plus random glitch bursts (a heading flickers with sliced, shifted colour copies and a jitter, at its own random times and strength, sometimes twice in a row) like an old VHS tape. The random timing is in the last lines of `script.js`; the strength and look of a burst are the `glBurst` and `glSlice` keyframes in `style.css`. The wave is the small “wavy page headings” script at the end of `script.js`; the look is the last section of `style.css`. It is switched off for people whose device is set to reduce motion.
- **Home page heading:** both O’s in “Moll’s Studio” are the spinning smiley (`images/smiley.png`), sized to the letter height (the two `<img class="o-spin">` pictures are written directly in the `<h1 class="home-title">` in `index.html`, so they show even before the script runs; their size is `h1.home-title .o-spin` in `style.css`).

## Important notes

- **PDF link:** PDFs use the placeholder `https://molls-studio.example`. Replace `PATTERN_SITE_URL` in `script.js` with the live website address when the domain is ready.
- **Photos in PDFs:** if the site is opened straight from the folder (not through a server), the browser may block photos from going into the PDF. On a live website they are included.
- **Keep images small:** large phone photos slow the site. Pictures under about 1 MB each, around 1500 pixels wide, are plenty.
- The CSS and JavaScript have section comments, and the HTML has comments marking the main page regions.


## Progress tracking and the Project journal
- **On a pattern page** (every pattern on the site): a yellow "Track your progress" box near the top. Press **Start tracking this project** and every step gets a tick box, and each chart gets a **Tick off the rows** list. A progress bar shows how far you are; ticks are saved on this device. **View in Project journal** opens that project’s tracker directly; **Start again** and **Stop tracking** are in the same box.
- **Patterns from the pattern maker:** press **Track progress** next to Save, or **Track progress** on a saved pattern in My Patterns, to open its tracker page. Each line of your instructions becomes a tick box (write one instruction per line), plus a row list for an attached colour chart. If you edit the pattern and press Track progress again, ticks stay on lines whose wording is unchanged.
- **PDF tracker option:** tick **Add tick boxes to the PDF (tracker)** next to the PDF button (on site patterns and in the pattern maker), or press **PDF with tick boxes** on a saved pattern. The PDF gets a tick box on every step, a row tracker for charts, a Started / Finished line and a notes page. In the journal, **Tracker PDF** prints your own progress (ticked steps are shown ticked).
- **Project journal:** a separate page under **My stuff** (also reached from Tools → Trackers → Project journal, and `#journal`). Projects appear as summary cards; open **Open tracker** to see a project on its own page, with its steps, chart rows, notes and progress controls. Use **Add a pattern or chart from My stuff** to import a saved pattern or chart. Saved patterns show their details, chart, photos, material checklist and instruction checklist; saved charts show a preview and row checkboxes. Ticks are saved with the project. Each tracker also has status (In progress, On hold, Finished; it turns Finished by itself when everything is ticked), **Open pattern/chart**, **Tracker PDF**, **Start again** and **Delete**. **Add your own project** makes a project with your own list of steps.
- Code: "progress tracking and the project journal" at the end of `script.js`. Projects are stored in `localStorage` under `molls-projects`; the tick-box drawing for PDFs is `pmDrawChecklist`, `pmDrawRowBoxes` and `pmDrawNoteLines`.

## Chart maker: picture colours, change a colour everywhere, preview lines
- **Colours from a picture** are now chosen the way the eye sees them (Lab colour space), counting how many squares use each colour. The fewer colours you ask for, the further apart they must be, so a small palette no longer wastes two colours on near-identical shades (for example two blues, or three skin tones). If the picture does not have that many clearly different colours you get fewer, and the message says how many. Code: `quant()` and `minDist()` in the "picture to chart" section of `script.js`.
- **Change selected colour (🎨):** in "Size and colour", select a swatch, then use the colour box next to it. Every square in the chart that uses that colour changes, live, and the swatch changes too. If you pick a colour that is already in the palette the two are joined into one. One Undo reverses the whole change, and Undo/Redo now also restore the palette. Code: "change a colour everywhere" in `script.js`, `#chc` in `index.html`.
- **White lines in the knitted preview** (thumbnails of larger colour charts, and the preview itself): `drawKnit()` now draws every stitch in its flat colour first, slightly wider than the stitch, and the knitted texture on top, so the soft edges between stitches no longer show the white page through.
- `images/disco-ball.gif`: the rave looks for this exact file name (a copy of the `disco ball.gif` with a space in it is included in this delivery).

## Chart maker: add/delete rows and columns, C3F / C3B cables
- New toolbox section "Add or delete rows and columns". Click a square on the chart (shown with a blue outline and row/column highlight), pick how many (1-50), then add a row above/below or column left/right, or delete the row above/below, this row, the column left/right, or this column. Row 1 is the bottom row. Works on every chart type, is one undo step, and keeps charts between 2 and 200 wide/high. Cables cut in half by an insert or delete are cleared so the written pattern stays correct.

## Garment preview: text, select area, front and back

## US / UK terms toggle on patterns (16 Nov 2026)
- Every site pattern page and every generated pattern (garment pattern writer and its View page) has a **Terms: US terms | UK terms** switch under the title (`termsMount`, `termsApply`, `termsConv`, `.termsbar`). The choice changes the words in the pattern straight away and is remembered (`localStorage 'molls-terms'`; first visit follows the browser language, en-US = US, otherwise UK).
- **Crochet** (the site's crochet patterns are written in US terms): US → UK turns sc / hdc / dc / tr into dc / htr / tr / dtr, single / half double / double / treble crochet into double / half treble / treble / double treble crochet, skip → miss, yarn over → yarn round hook, gauge → tension, and the heading "(US crochet terms)" → "(UK crochet terms)".
- **Knitting and crochet**: bind off ↔ cast off, stockinette ↔ stocking stitch, seed stitch ↔ moss stitch, gauge ↔ tension, color ↔ colour (also colorwork, gray).
- The "Download PDF" button on a site pattern copies the page, so the PDF uses the chosen terms. Saved patterns keep their original wording (the switch is only a view), so Save / My Patterns exports are unaffected.
- To add a word, edit `TERMS_BOTH_UK`, `TERMS_CRO_UK` and `TERMS_BOTH_US` above `showPattern()`.
